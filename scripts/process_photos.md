# Обработка фотографий товаров

Исходники: `assets-src/photos/*.webp` (присланные фото на ковре).

1. Кадрирование каждой позиции по координатам (см. таблицу в истории коммитов / `boxes` ниже).
2. Удаление фона нейросетью `rembg` (модели `isnet-general-use` для желе и чая, `u2net` для бутылочек Hi Baby).
3. Пакет латяо — перспективное выравнивание (`convert -distort Perspective`) и скругление углов.
4. Сглаживание края маски (erode 2px + blur 1px), лёгкая коррекция насыщенности и резкости,
   вписывание в холст 720x900 с прозрачным фоном, экспорт WebP (полный размер и 360px превью).

```
boxes = {
 'hibaby-strawberry': (1, (20,600,490,1620)),
 'hibaby-peach':      (1, (520,600,970,1620)),
 'hibaby-original':   (1, (970,600,1440,1620)),
 'jelly-peach':       (2, (130,380,690,1600)),
 'jelly-strawberry':  (2, (700,380,1290,1660)),
 'milktea-jasmine':   (3, (210,500,740,1560)),
 'milktea-original':  (3, (730,540,1260,1560)),
}
lobster perspective: '508,238 0,0  1090,373 640,0  1103,1578 640,1260  354,1553 0,1260'
```

Позиции без фото нарисованы скриптом `scripts/gen-illustrations.mjs` (SVG -> Chromium -> WebP).
В админ-панели любое изображение можно заменить реальной фотографией.
